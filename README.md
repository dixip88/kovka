# Kovka

Инфраструктурная платформа для адаптации и оркестрации языковых моделей под русский контекст.
Infrastructure for Russian-context LLM adaptation & orchestration.

> 🚧 **Статус:** Проект находится на этапе переименования и реструктуризации (ex-cat.ai). Публичный релиз планируется в Q3 2026.

## О проекте
Kovka — это не модель, а инструмент. Платформа предназначена для:
-   Адаптации базовых LLM к русскоязычным паттернам и задачам.
-   Оркестрации множества специализированных моделей в единой среде.
-   Этичной кастомизации без присвоения авторства базовым архитектурам.
